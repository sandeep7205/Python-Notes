# 🔨 3–5 min — Understand Decisions in Python

In real life, we make decisions based on conditions:

> "If it rains, carry an umbrella. Else, leave it at home."

In Python:

```python
if condition:
    # runs if condition is True
elif another_condition:
    # runs if previous was False and this is True
else:
    # runs if none of the above were True
```

`elif` and `else` are optional, but together they let you handle multiple distinct scenarios cleanly.
