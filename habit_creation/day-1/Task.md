# 🔨 3–5 min — Understand Variables & Types

Think of a variable as a **name/label that refers to a value**:

```python
experience = 3.8
```

Here:
* `experience` → the variable name
* `3.8` → the value
* `=` → assignment operator (stores/binds the value to the name)

The basic data types you'll use constantly:
* `int` → whole numbers (e.g., `1`, `42`)
* `float` → decimal numbers (e.g., `3.8`, `99.9`)
* `str` → text wrapped in single or double quotes (e.g., `"Sandeep"`, `'Python'`)
* `bool` → truth values (`True` or `False`)
